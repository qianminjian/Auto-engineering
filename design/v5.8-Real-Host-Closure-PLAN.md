# Real Host Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `test-driven-development` and execute each checkbox in order. Do not write production code before observing the corresponding RED failure.

**Goal:** 建立真实宿主必须消费的严格 Worker 调用协议、可验证设计决策账本和分层产品验收，使完整设计文档可稳定执行到业务终态。

**Architecture:** Core 继续保持确定性治理；`spawn.invocations[]` 是单/多 Worker 的唯一机器合同，Host Driver 逐项执行并回传 attestation。WorkerOutcome 与 Coordinator StageResult 分离；Design Decision Ledger 把来源权威转成可验证义务。Fake Host 运行完整 Tick/EventStore 轨迹，真实产品验收按 Canary 和完整黄金项目分层。

**Tech Stack:** Python 3.12+、dataclass/StrEnum、JSON Schema、pytest、现有 Tick/EventStore/Prompt Contract。

> **2026-08-12 审计说明：** Task 1-5 的勾选只表示基础模块和定向测试已完成，不表示
> 生产宿主闭环成立。审计发现 Worker/Coordinator 输出污染、生产调用未绑定、设计权威无
> 决策账本、Fake Host 非完整轨迹和黄金 fixture 自证等缺口，由 Task 7-13 统一收敛。
