# Protocol Kernel Convergence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已叠加在旧 TickOrchestrator 外围的协议、事件、Handler、Prompt 和 Host 能力收敛为一个可跨版本连续运行的确定性协议内核。

**Architecture:** 保持 Action/Result v1.1 和单 Tick Core，通过兼容扩展增加 Execution Control；使用 Runtime Compatibility Vector 在 Action 边界激活新 Prompt/Policy；以显式领域事件 Reducer 替代新 Tick 的完整状态快照；按 Stage 绞杀旧 façade，不建立第二内核。

**Tech Stack:** Python 3.12、Click、SQLite、JSON Schema 2020-12、pytest、Ruff、mypy、Claude Code/Codex Plugin assets。
