# Prompt Contract 兼容式重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `test-driven-development` and
> `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`)
> syntax for tracking.

**Goal:** 在保持 Action/Result v1.1 兼容的前提下，保证每个执行角色获得真实上下文、
统一输出契约和可验证的多 Agent 完成证据。

**Architecture:** 新增内部 Prompt Contract 与 Compiler，由 ActionBuilder 消费；
角色 Markdown 只保留稳定方法论。逐步替换当前字符串拼接、静默模板兜底和单 proof
覆盖机制，并将日志改为不可覆盖的渲染证据。

**Tech Stack:** Python 3.11+、dataclass、JSON Schema、pytest、现有 PromptRegistry。
