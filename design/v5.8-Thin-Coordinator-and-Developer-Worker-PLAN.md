# Thin Coordinator and Developer Worker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development and executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Developer 从主会话 inline 执行迁移为单个隔离 Worker，并以有界结果保持 Coordinator 只承担确定性调度。

**Architecture:** Core 继续生成 Canonical Action；`developer` 使用与 Architect/Critic 相同的严格 SpawnPlan、digest-bound launcher 和 HostExecutionAssembler。Coordinator 只消费 compact envelope 和 Action-scoped work files，D13、EventStore、Result schema 与恢复协议不变。

**Tech Stack:** Python 3.12、pytest、Pydantic/JSON Schema、现有 Host Adapter 与 EventStore。
