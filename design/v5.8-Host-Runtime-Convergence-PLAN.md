# Host Runtime Product Closure Implementation Plan

**Goal:** 关闭真实宿主自动续跑、Worker 证据、事件状态、设计权威和产品验收之间的断链。

**Architecture:** Core 保持单 Tick；插件层 HostRuntimeDriver 管理一次用户启动内的执行义务，HostExecutionAssembler 原子固化真实 Worker 证据；EventStore + Reducer 成为进度和指标唯一事实源。

**Tech Stack:** Python 3.12+、SQLite EventStore、JSON Schema、pytest、Claude/Codex Plugin assets。
